# Welcome To Update Password-CCPros Edition

 Change the password of any windows computer by a click of a button.</br>The application needs to be run as an administrator for it to work properly.

## How the app works?

 By default the app launch with the **Update Password** button and **Change Password** ratio button activated.

## How do i know a button is clickable

 To know is a button is clickable, you can hover your mouse cursor on the button</br>
 if the cursor change from the default **arrow** icon to the **hand** icon, then it is</br>
 clickable.
